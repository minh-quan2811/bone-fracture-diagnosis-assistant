# CLIP Folder

## Purpose

This folder contains experiments and utilities for working with **BioMedCLIP**, a vision-language model for medical images. The main goals are:

- **Explore model structure** - Understand the architecture and components of BioMedCLIP
- **Visualize explanations** - Generate visual explanations showing what the model focuses on when analyzing medical images
- **Classify and analyze** - Use the model to classify bone fractures and other medical conditions

## Subfolders

- **`visualize/`** - Visual explanation tools that show model reasoning using multiple explainability methods (Grad-CAM, attention rollout, etc.)
- **`data/`** - Medical image datasets organized by anatomical region
- Other experimental tools and analysis scripts

## Key Features

- Multiple explainability methods for interpretable AI
- Integration with BioMedCLIP for medical image understanding
- Configurable visualization pipeline for different images and text prompts
